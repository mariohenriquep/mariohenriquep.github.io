02O que fazWhat it does

  1. Projetos e equipas. Quem cria um projeto fica Gestor e adiciona membros pelo email; projetos terminados vão para um arquivo só de leitura.
  2. Tarefas. Prioridade, prazo, estado, vários responsáveis e comentários; as atrasadas ficam assinaladas.
  3. Kanban. Quadro por projeto e quadro geral, com filtros guardados no endereço da página.
  4. Acesso seguro. JWT, bcrypt, bloqueio após tentativas falhadas, limites de pedidos e um registo que não revela que emails existem.
  1. Projects and teams. Whoever creates a project becomes its Manager and adds members by email; finished projects move to a read-only archive.
  2. Tasks. Priority, deadline, status, multiple assignees and comments; overdue tasks are flagged.
  3. Kanban. Per-project board and an overview board, with filters kept in the page URL.
  4. Secure access. JWT, bcrypt, lockout after failed attempts, rate limiting and a sign-up flow that doesn't reveal which emails exist.

03Como foi feitaHow it was built

Em cinco fases, na unidade curricular AI-Powered Software Engineering, cada uma revista antes de avançar.

In five phases, for the AI-Powered Software Engineering course, each reviewed before moving on.

  1. Especificação. Requisitos, user stories com critérios de aceitação e restrições.
  2. Arquitetura. Monólito modular, modelo de dados e contrato REST em OpenAPI.
  3. Implementação. Spring Boot em clean architecture (verificada com ArchUnit) e React.
  4. Testes e revisões. Testcontainers, Playwright, code review e security review.
  5. Entrega. Docker, GitHub Actions com Trivy e SonarQube Cloud, versões com tags e deploy no Render.
  1. Specification. Requirements, user stories with acceptance criteria, and constraints.
  2. Architecture. Modular monolith, data model and a REST contract in OpenAPI.
  3. Implementation. Spring Boot in clean architecture (enforced with ArchUnit) and React.
  4. Testing and reviews. Testcontainers, Playwright, code and security reviews.
  5. Delivery. Docker, GitHub Actions with Trivy and SonarQube Cloud, tagged releases and deployment on Render.
IA com revisão humana.AI with human review.
Usei IA em todas as fases, como copiloto: prompts estruturados, registo do uso e revisão humana de cada decisão, código e teste. I used AI as a copilot in every phase: structured prompts, a usage log and human review of every decision, piece of code and test.
